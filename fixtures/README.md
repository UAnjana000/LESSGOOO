# Fixtures: synthetic test content only

**Nothing in this folder is a work of Dr. B. R. Ambedkar**, and nothing in it is copied from any real archive.

All text, page images, the illustration, and the audio clip were generated by `generate_fixtures.py` for testing:

- **Author.** "A. N. Example" is fictional.
- **Place.** The town of Samarpur is fictional.
- **Audio.** The audio is espeak-ng synthetic speech.
- **Video.** `fx-talk-video-synthetic.mp4` is an FFmpeg test pattern (`testsrc2`) carrying the same synthetic talk, so its transcript timings match the audio fixture. Its title metadata says it is not a historical recording.
- **Illustration.** The picture is drawn programmatically.
- **Tags and Constitution links.** `seed-fixtures` adds subject, person and place tags to fixture items and one demonstration link from the fictional Assembly proceedings to Article 41. The link note says it is a synthetic demonstration, not a historical claim.
- **Labels.** Every page image carries a visible "synthetic fixture" label, and every rights record is marked `is_fixture: true`.

| File | Purpose |
|---|---|
| `manifests/fixture_manifest.json` | Rights register and source manifest for the fixtures, with SHA-256 for each file |
| `manifests/example_real_sources.manifest.json` | Template for the real sources in spec §11. All permissions are `unknown` and downloads are disabled, so the importer refuses to ingest the content. NDLI is marked discovery-only. |
| `ground_truth.json` | Exact text for each fixture page, used for OCR smoke evaluation and seeded reviews |
| `capture-demo-page.png` | Stands in for a new capture in the live-path demo (spec §8.2) |
| `files/` | Generated originals: born-digital PDFs, clean and degraded printed scans, a two-page spread, Hindi and Marathi pages, a handwritten note, an illustration, audio, and a test-pattern video |

## Seeded reviews are not human reviews

`python -m archive.cli seed-fixtures` approves fixture pages using the known ground truth, so the demo has published content. Those approvals have the following properties:

- The reviewer is recorded as `fixture-seed`.
- Each decision has `is_seeded_fixture = true`.
- The visitor UI shows a fixture banner.

They demonstrate the workflow only. They are not evidence of human review, quote verification, or translation review.

## Regenerate

```powershell
docker compose run --rm api python /fixtures/generate_fixtures.py --out /fixtures
```
